DP Learning Pointers — Learn These Before Memorising Any Code

1. State first.
dp[...] = answer for ___ using / ending at ___. If you cannot say this exactly, do not code.
2. Find the final decision.
Ask: “What was the last move, last item, first cut, or last operation that reaches this state?”
3. Identify the operation.
Count → add; minimum → min; maximum → max; feasibility → boolean OR; games → my gain minus opponent answer.
4. Loop order changes the problem.
sum outer = ordered; coin outer + forward = unlimited combinations; item outer + backward = 0/1.
5. Base cases are meaning.
Decide what empty prefix, sum 0, one cell, one interval, or no selected item should mean before transition.
6. Compress only after 2D is clear.
Previous-row dependency → prev/cur. Backward 1D loop protects 0/1 states. Forward loop permits reuse.
7. String template.
Equal characters usually use diagonal. Unequal characters either skip one side or try insert/delete/replace.
8. Interval template.
dp[l][r] solves a range. Choose a first cut / endpoint / last operation that makes subproblems independent.
9. Advanced only after basics.
Subset DP, profile DP, digit DP, Fenwick DP and segment-tree DP are not “new DP”; they are state design plus data structures.

1D Counting / Minimum DP

Dice Combinations

count · ordered · unlimited
1. Goal / Pattern
Count ordered sequences of fixed moves that reach an exact total.
2. Best Approach
O(n) time, O(n) space. 1D native; modulo.
3. DP State
dp[s] = number of ordered dice-roll sequences with sum exactly s.
4. Transition + Base
dp[s] = Σ dp[s-d] for d in 1..6 and d≤s. Base: dp[0]=1.
5. Iteration Order
Sum forward, then face. Rolls can repeat; sum outer makes order matter.
7. Catch / Memory Hook
Use long before modulo. Memory hook: “sum outer = ordered sequences.”
8. Similar / Difference
Coin Combinations I: same sum-outer counting structure; dice values are fixed 1..6.
9. Interview One-Liner
“For each total, choose the final dice face and add ways for the remaining total.”

public class Main {
    static final long MOD = 1_000_000_007L;

    static final class FastScanner {
        private final byte[] buffer = new byte[1 << 16];

        private int read() throws IOException {

                ptr = 0;
                if (len < 0) return -1;
            }
            return buffer[ptr++] & 255;
        }

        String next() throws IOException {
            StringBuilder sb = new StringBuilder();
            int c;
            do { c = read(); } while (c <= 32 && c != -1);
            while (c > 32 && c != -1) {
                sb.append((char) c);
                c = read();
            }
            return sb.toString();
        }

        int nextInt() throws IOException { return Integer.parseInt(next()); }
        long nextLong() throws IOException { return Long.parseLong(next()); }
    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner();
        int n = fs.nextInt();

        long[] dp = new long[n + 1];
        dp[0] = 1;

        for (int sum = 1; sum <= n; sum++) {
            for (int face = 1; face <= 6 && face <= sum; face++) {
                dp[sum] += dp[sum - face];
                if (dp[sum] >= MOD) dp[sum] -= MOD;
            }
        }
        System.out.println(dp[n]);
    }
}

Minimizing Coins

min · unlimited coin change
1. Goal / Pattern
Minimum number of reusable choices needed to make an exact target sum.
2. Best Approach
O(n·x) time, O(x) space. 1D native; no modulo.
3. DP State
dp[s] = minimum coins needed to make exact sum s; INF means impossible.
4. Transition + Base
dp[s] = min(dp[s], dp[s-c]+1) for every coin c≤s. Base: dp[0]=0.
5. Iteration Order
Sum forward. A state dp[s-c] may already use coin c, so reuse is allowed.
7. Catch / Memory Hook
Do not compute INF+1. Memory hook: “INF means impossible, not expensive.”
8. Similar / Difference
Coin Combinations I uses the same last-coin idea but adds counts; this minimizes.
9. Interview One-Liner
“I try every legal last coin and keep the smallest answer for the remainder.”

Coin Combinations I

count · ordered · unlimited
1. Goal / Pattern
Count reusable coin sequences where different orders are different answers.
2. Best Approach
O(n·x) time, O(x) space. 1D optimal; modulo.
3. DP State
dp[s] = number of ordered coin sequences summing exactly to s.
4. Transition + Base
dp[s] += dp[s-c] for every c≤s; append c as the final coin. Base: dp[0]=1.
5. Iteration Order
Sum outer, coin inner. That enumerates every choice of final coin, so order matters.
7. Catch / Memory Hook
Never swap the loops accidentally. Memory hook: “sum outer = permutations.”
8. Similar / Difference
Coin Combinations II has the same symbols but coin outer; it counts unordered combinations.
9. Interview One-Liner
“I append each possible final coin to a sequence for the remaining sum.”

Coin Combinations II

count · unordered · unlimited
1. Goal / Pattern
Count coin multisets: different orders of the same selected coins are one answer.
2. Best Approach
O(n·x) time, O(x) space. 1D optimal; modulo.
3. DP State
After processed coin types, dp[s] = number of combinations making sum s.
4. Transition + Base
For current coin c: dp[s] += dp[s-c]. Base: dp[0]=1.
5. Iteration Order
Coin outer, sum forward. Forward permits reuse; fixed type order removes permutations.
7. Catch / Memory Hook
Memory hook: “coin outer = combinations; forward = unlimited.”
8. Similar / Difference
Coin I is sum outer and ordered; Coin II is coin outer and unordered. Both reuse coins.
9. Interview One-Liner
“I process denominations in fixed order so every multiset has one construction order.”

Removing Digits

min · state-dependent moves
1. Goal / Pattern
Minimum moves to reach zero when valid subtractions are the nonzero digits of the current number.
2. Best Approach
O(n·digits(n)) time, O(n) space. 1D native.
3. DP State
dp[x] = minimum moves needed to reduce integer x to zero.
4. Transition + Base
dp[x] = 1 + min(dp[x-d]) over each nonzero digit d occurring in x. Base: dp[0]=0.
5. Iteration Order
Process x from 1 to n. Each transition goes to a smaller number; no fixed item-reuse rule.
7. Catch / Memory Hook
Ignore digit 0. Memory hook: “read digits from current x, not original n.”
8. Similar / Difference
Minimizing Coins also chooses a last move, but its coin set is global; here it changes with x.
9. Interview One-Liner
“Every state points only to smaller numbers, so I test each nonzero digit as the next subtraction.”

Counting Towers

count · two boundary states
1. Goal / Pattern
Width-2 construction where only the top boundary profile affects future extensions.
2. Best Approach
O(maxN) preprocessing time, O(maxN) space. Rolling O(1) is possible; modulo.
3. DP State
a[i], b[i] = number of towers of height i ending in the two canonical width-2 boundary forms.
4. Transition + Base
a[i]=4a[i-1]+b[i-1]; b[i]=a[i-1]+2b[i-1]. Base: a[1]=b[1]=1. Answer a[n]+b[n].
5. Iteration Order
Height forward. Each level depends only on the previous frontier state.
7. Catch / Memory Hook
Use long before modulo. Memory hook: “small fixed width → classify frontier shapes.”
8. Similar / Difference
Counting Tilings uses the same frontier principle but needs 2^width masks; width 2 collapses to two states.
9. Interview One-Liner
“The full past compresses into the exposed top shape, so two states are enough.”

Grid / Local-Constraint DP

Grid Paths I

grid count · obstacles
1. Goal / Pattern
Count monotone right/down paths through a grid with blocked cells.
2. Best Approach
O(n²) time, O(n) space by row compression; modulo.
3. DP State
After processing row i, dp[j] = number of paths to cell (i,j).
4. Transition + Base
Open cell: dp[j] = dp[j] (from up) + dp[j-1] (from left). Blocked: dp[j]=0. Base: dp[0]=1.
5. Iteration Order
Rows top-down; columns left-right. Current dp[j] is up, updated dp[j-1] is left.
7. Catch / Memory Hook
A blocked cell must erase its old from-up value. Memory hook: “obstacle = zero state.”
8. Similar / Difference
Minimal Grid Path has same geometry but retains tied lexicographic frontier states instead of adding counts.
9. Interview One-Liner
“Every path into a cell arrives from above or left, so one row is sufficient.”

Array Description

count · adjacent values
1. Goal / Pattern
Count arrays with |a[i]-a[i-1]|≤1 when some positions are fixed and others are zero.
2. Best Approach
O(n·m) time, O(m) space using previous/current rows; modulo.
3. DP State
prev[v] = ways to fill processed prefix ending with value v, where 1≤v≤m.
4. Transition + Base
If v is allowed at i: cur[v] = prev[v-1]+prev[v]+prev[v+1]. Base: each allowed first value has one way.
5. Iteration Order
Process positions left-to-right. Use two rows because every transition must read the untouched previous position.
7. Catch / Memory Hook
Pad indexes 0 and m+1 with zero. Memory hook: “local constraint → nearby previous states only.”
8. Similar / Difference
Grid Paths uses geometric predecessors; Array Description uses value neighbours v-1, v and v+1.
9. Interview One-Liner
“The next choice only cares about the last value, so the entire prefix compresses to one endpoint.”

Minimal Grid Path

lexicographic · frontier DP
1. Goal / Pattern
Find the lexicographically smallest right/down path string; simple greedy fails when the best next letter ties.
2. Best Approach
O(n²) time, O(n²) grid storage plus O(n) frontier. No scalar 1D DP.
3. DP State
Frontier[d] = every cell on diagonal i+j=d that is reachable by the lexicographically minimum prefix of length d+1.
4. Transition + Base
From all frontier cells, choose smallest right/down neighbour character. Next frontier contains all neighbours with that character. Base: {(0,0)}.
5. Iteration Order
Move diagonal by diagonal. Keep all tied best cells because any one could enable a better later suffix.
7. Catch / Memory Hook
Never retain only one tie. Memory hook: “equal best letter → keep every future possibility.”
8. Similar / Difference
Grid Paths I adds number of routes; this minimizes the path label and must preserve all equally best prefixes.
9. Interview One-Liner
“At each diagonal I keep every cell producing the best prefix, then extend only with the smallest available letter.”

import java.util.*;

public class Main {
    static int n;
    static char[][] grid;

    static final class FastScanner {
        private final byte[] buffer = new byte[1 << 16];
        private int ptr = 0, len = 0;

        private int read() throws IOException {
            if (ptr >= len) {
                len = System.in.read(buffer);
                ptr = 0;
                if (len < 0) return -1;
            }
            return buffer[ptr++] & 255;
        }

        String next() throws IOException {
            StringBuilder sb = new StringBuilder();
            int c;
            do { c = read(); } while (c <= 32 && c != -1);
            while (c > 32 && c != -1) {
                sb.append((char) c);
                c = read();
            }
            return sb.toString();
        }

        int nextInt() throws IOException { return Integer.parseInt(next()); }
        long nextLong() throws IOException { return Long.parseLong(next()); }
    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner();
        n = fs.nextInt();

        grid = new char[n][];
        for (int i = 0; i < n; i++) grid[i] = fs.next().toCharArray();

        int[] cur = new int[n];
        int[] next = new int[n];
        int[] seen = new int[n];
        Arrays.fill(seen, -1);

        int size = 1;
        cur[0] = 0; // row 0; column is determined by the diagonal
        StringBuilder answer = new StringBuilder();
        answer.append(grid[0][0]);

        for (int diagonal = 1; diagonal <= 2 * n - 2; diagonal++) {
            char best = '['; // one character after 'Z'

            for (int k = 0; k < size; k++) {
                int row = cur[k];
                int col = diagonal - 1 - row;

                if (row + 1 < n) best = (char) Math.min(best, grid[row + 1][col]);
                if (col + 1 < n) best = (char) Math.min(best, grid[row][col + 1]);
            }

            int nextSize = 0;
            for (int k = 0; k < size; k++) {
                int row = cur[k];
                int col = diagonal - 1 - row;

                int downRow = row + 1;
                if (downRow < n && grid[downRow][col] == best && seen[downRow] != diagonal) {
                    seen[downRow] = diagonal;
                    next[nextSize++] = downRow;
                }

                if (col + 1 < n && grid[row][col + 1] == best && seen[row] != diagonal) {
                    seen[row] = diagonal;
                    next[nextSize++] = row;
                }
            }

            answer.append(best);

Money Sums

0/1 subset feasibility
1. Goal / Pattern

2. Best Approach

8. Similar / Difference

Two Sets II

0/1 count · partition
1. Goal / Pattern
Count equal-sum partitions of {1..n} without double-counting complementary subsets.
2. Best Approach
O(n·T) time, O(T) space, where T=n(n+1)/4. 1D possible; modulo.
3. DP State
dp[s] = number of subsets of processed values that sum to s.

5. Iteration Order
Value outer; sum backward. Each number is 0/1. Excluding n counts each partition once.
7. Catch / Memory Hook
Memory hook: “skip n instead of dividing by 2.”
8. Similar / Difference
Money Sums uses same backward 0/1 DP but stores boolean reachability for all totals rather than count for one target.
9. Interview One-Liner

Elevator Rides

subset DP · lexicographic state
1. Goal / Pattern
Partition at most 20 people into the minimum number of capacity-limited rides.
2. Best Approach
O(n·2^n) time, O(2^n) space. Mask DP is optimal for n≤20.
3. DP State
For mask: (rides[mask], lastWeight[mask]) is minimum rides; among ties, minimum current last-ride weight.
4. Transition + Base
Remove person p. Append if lastWeight+w[p]≤x; otherwise start a new ride. Keep lexicographic minimum pair. Base: (1,0) for empty mask.
5. Iteration Order
Process masks in increasing numeric order; a mask represents people used exactly once.
7. Catch / Memory Hook
Always tie-break on lower current ride weight. Memory hook: “min rides first, lighter open ride second.”
8. Similar / Difference
Book Shop tracks total cost only; this problem needs the exact subset of people plus the best unfinished ride.
9. Interview One-Liner
“For each subset I store the fewest rides and the lightest possible open last ride.”

String / Interval DP

Edit Distance

string prefix DP · min
1. Goal / Pattern
Minimum insertions, deletions and replacements to transform one string into another.
2. Best Approach
O(n·m) time, O(m) space with rolling rows.
3. DP State
dp[i][j] = minimum operations converting first i characters of a into first j characters of b.

8. Similar / Difference

8. Similar / Difference
Rectangle Cutting adds independent child answers; games subtract the opponent’s best remaining advantage.

Advanced CSES DP

Mountain Range

advanced · monotonic stack + segment tree
1. Goal / Pattern
Longest descending route where a jump from a must have every crossed mountain strictly lower than a.
2. Best Approach
O(n log n) time, O(n) space: nearest greater-or-equal blockers + offline range-max DP.
3. DP State
dp[i] = maximum mountains visitable when the route starts at i.
4. Transition + Base
Let L[i],R[i] be nearest indices with height ≥ h[i]. Then dp[i]=1+max(dp[j]) for j in [L[i]+1,R[i]-1] with h[j]<h[i]. Process equal heights as one batch.
5. Iteration Order
Build blockers with monotonic stacks. Process heights ascending; query the segment tree before updating all mountains of equal height.
7. Catch / Memory Hook
Use >= blockers: equal-height mountains block visibility. Batch equal heights so they do not transition into each other.
8. Similar / Difference
LIS also transitions to smaller values; Mountain Range restricts destination indices to the interval between nearest taller/equal blockers.
9. Interview One-Liner
“Nearest higher blockers define the visible interval; a segment tree gives the best lower route inside it.”

import java.io.*;
import java.util.*;

public class Main {
    static final class SegmentTree {
        int size;
        int[] tree;

        SegmentTree(int n) {
            size = 1;
            while (size < n) size <<= 1;
            tree = new int[size << 1];
        }

        void update(int position, int value) {
            int node = position + size;
            tree[node] = Math.max(tree[node], value);
            for (node >>= 1; node > 0; node >>= 1) {
                tree[node] = Math.max(tree[node << 1], tree[node << 1 | 1]);
            }
        }

        int query(int left, int right) {
            if (left > right) return 0;
            int result = 0;
            for (left += size, right += size; left <= right; left >>= 1, right >>= 1) {
                if ((left & 1) == 1) result = Math.max(result, tree[left++]);
                if ((right & 1) == 0) result = Math.max(result, tree[right--]);
            }
            return result;
        }
    }

        private final byte[] buffer = new byte[1 << 16];
        private int ptr = 0, len = 0;

        private int read() throws IOException {

                ptr = 0;
                if (len < 0) return -1;

            return buffer[ptr++] & 255;

                sb.append((char) c);

    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner();
        int n = fs.nextInt();

        int[] h = new int[n];
        for (int i = 0; i < n; i++) h[i] = fs.nextInt();

        int[] left = new int[n];
        int[] right = new int[n];
        int[] stack = new int[n];
        int top = 0;

        // Nearest previous height >= current height.
        for (int i = 0; i < n; i++) {
            while (top > 0 && h[stack[top - 1]] < h[i]) top--;
            left[i] = top == 0 ? -1 : stack[top - 1];

        top = 0;
        for (int i = n - 1; i >= 0; i--) {
            while (top > 0 && h[stack[top - 1]] < h[i]) top--;
            right[i] = top == 0 ? n : stack[top - 1];
            stack[top++] = i;
        }

        // Sort by height ascending; lower mountains must be ready before higher mountains.
        long[] order = new long[n];
        for (int i = 0; i < n; i++) {
            order[i] = ((long) h[i] << 32) | (i & 0xffffffffL);
        }
        Arrays.sort(order);

        SegmentTree segmentTree = new SegmentTree(n);
        int[] dp = new int[n];
        int answer = 1;

        for (int p = 0; p < n; ) {
            int q = p;
            long height = order[p] >>> 32;
            while (q < n && (order[q] >>> 32) == height) q++;

            // Query before update: equal heights are not valid destinations.
            for (int t = p; t < q; t++) {
                int index = (int) order[t];
                dp[index] = 1 + segmentTree.query(left[index] + 1, right[index] - 1);
                answer = Math.max(answer, dp[index]);
            }

            for (int t = p; t < q; t++) {
                int index = (int) order[t];
                segmentTree.update(index, dp[index]);
            }

            p = q;
        }

        System.out.println(answer);
    }
}

Counting Tilings

profile DP · bitmask frontier
1. Goal / Pattern
Count domino tilings when one grid dimension is small and the frontier occupancy is all that matters.
2. Best Approach
O(m·3^n) time, O(2^n) space. Use the smaller dimension as the bitmask width.
3. DP State
dp[mask] = ways before a column where mask bits are cells already occupied by horizontal dominoes from the previous column.
4. Transition + Base
Fill the first empty row: vertical tile fills two current cells; horizontal tile fills current cell and sets nextMask bit. Base dp[0]=1.
5. Iteration Order
Process columns left-to-right. Recursively fill rows within current mask.
7. Catch / Memory Hook
Mask means occupied from the left. Memory hook: “horizontal placement sets a bit in nextMask.”
8. Similar / Difference
Counting Towers is also frontier DP, but width 2 has only two canonical profiles instead of 2^n masks.
9. Interview One-Liner
“I sweep columns and remember only cells pre-filled by dominoes crossing from the left.”

import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1_000_000_007L;
    static int rows;
    static long[] nextDp;

    static void fillColumn(int row, int mask, int nextMask, long ways) {
        if (row == rows) {
            nextDp[nextMask] += ways;
            if (nextDp[nextMask] >= MOD) nextDp[nextMask] -= MOD;
            return;
        }

        if ((mask & (1 << row)) != 0) {
            fillColumn(row + 1, mask, nextMask, ways);
            return;
        }

        fillColumn(row + 1, mask | (1 << row), nextMask | (1 << row), ways);

        // Vertical domino: it occupies two rows in the current column.
        if (row + 1 < rows && (mask & (1 << (row + 1))) == 0) {
            fillColumn(row + 2,
                mask | (1 << row) | (1 << (row + 1)),
                nextMask,
                ways);
        }
    }

1. Goal / Pattern

Top-down memoization over digit positions. Digits are picked once per position.
7. Catch / Memory Hook
Leading zeros must not behave like repeated zeroes. Memory hook: “started decides whether prev exists.”

Increasing Subsequence II

count · Fenwick tree DP
1. Goal / Pattern
Count all strictly increasing subsequences when values and n are large.
2. Best Approach
O(n log n) time, O(n) space: coordinate compression plus Fenwick prefix sums; modulo.
3. DP State
ways[i] = increasing subsequences ending at index i; Fenwick stores summed ways by ending-value rank.
4. Transition + Base
ways = 1 + sum(ranks < rank(a[i])); then add ways at rank(a[i]).
5. Iteration Order
Scan indexes left-to-right. Query rank-1, then update rank; equal values cannot extend each other.
7. Catch / Memory Hook
Query rank-1, never rank. Memory hook: “strictly increasing = query smaller, then update.”
8. Similar / Difference
LIS stores the smallest tail for each length; this sums the counts of all valid smaller endpoints.
9. Interview One-Liner
“Every subsequence ending at x is either [x] or a previous subsequence ending with a smaller value plus x.”

import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1_000_000_007L;

    static final class Fenwick {
        int n;
        long[] bit;

        Fenwick(int n) {
            this.n = n;
            this.bit = new long[n + 1];
        }

        void add(int index, long value) {
            for (int i = index; i <= n; i += i & -i) {
                bit[i] += value;
                if (bit[i] >= MOD) bit[i] -= MOD;
            }
        }

        long sum(int index) {
            long result = 0;
            for (int i = index; i > 0; i -= i & -i) {
                result += bit[i];
                if (result >= MOD) result -= MOD;
            }
            return result;
        }
    }

        private final byte[] buffer = new byte[1 << 16];

            int c;

            while (c > 32 && c != -1) {
                sb.append((char) c);
                c = read();
            }
            return sb.toString();
        }

    }

        int[] values = a.clone();
        Arrays.sort(values);

        int unique = 0;
        for (int value : values) {
            if (unique == 0 || values[unique - 1] != value) {
                values[unique++] = value;
            }
        }

        Fenwick fenwick = new Fenwick(unique);
        long answer = 0;

        for (int value : a) {
            int rank = Arrays.binarySearch(values, 0, unique, value) + 1;
            long ways = 1 + fenwick.sum(rank - 1);
            if (ways >= MOD) ways -= MOD;

            fenwick.add(rank, ways);
            answer += ways;
            if (answer >= MOD) answer -= MOD;
        }

        System.out.println(answer);
    }

Matching ends: 2+dp[left+1][right-1]. Else: max(dp[left+1][right], dp[left][right-1]). Base dp[i][i]=1.
5. Iteration Order
Left index descends and right index ascends, so smaller intervals are available.
7. Catch / Memory Hook
Do not confuse subsequence with substring. Memory hook: “matching ends are worth two; otherwise drop one end.”
8. Similar / Difference
LCS compares two prefixes; LPS compares two ends of one interval and requires mirrored matches.
9. Interview One-Liner
“A palindrome either uses matching endpoints or discards one endpoint to get the best smaller interval.”

class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];

        for (int left = n - 1; left >= 0; left--) {
            dp[left][left] = 1;

            for (int right = left + 1; right < n; right++) {
                if (s.charAt(left) == s.charAt(right)) {
                    dp[left][right] = 2 + (right == left + 1 ? 0 : dp[left + 1][right - 1]);
                } else {
                    dp[left][right] = Math.max(dp[left + 1][right], dp[left][right - 1]);
                }
            }
        }

        return n == 0 ? 0 : dp[0][n - 1];
    }
}

Maximal Square

LeetCode 221 · grid max
1. Goal / Pattern
Find the area of the largest all-1 square in a binary matrix.
2. Best Approach
O(rows·cols) time, O(cols) space.
3. DP State
dp[j] = largest all-1 square side ending at current row and column j.
4. Transition + Base
If cell is 1: 1+min(up,left,diagonal); otherwise 0. Base virtual zero row and column.
5. Iteration Order
Rows top-down, columns left-right. Save old dp[j] as diagonal before overwriting.
7. Catch / Memory Hook
Memory hook: “a square grows only as far as its weakest neighbour.”
8. Similar / Difference
Grid Paths adds predecessors to count routes; Maximal Square takes their minimum to guarantee a complete square.
9. Interview One-Liner
“A 1-cell grows a square only when up, left and diagonal can all support the next side length.”
6. Full Java 17 Code — LeetCode-ready: class Solution
class Solution {
    public int maximalSquare(char[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;

        int[] dp = new int[cols + 1];
        int bestSide = 0;

        for (int row = 0; row < rows; row++) {
            int diagonal = 0;

            for (int col = 1; col <= cols; col++) {
                int up = dp[col];

                if (matrix[row][col - 1] == '1') {
                    dp[col] = 1 + Math.min(diagonal, Math.min(dp[col], dp[col - 1]));
                    bestSide = Math.max(bestSide, dp[col]);
                } else {
                    dp[col] = 0;
                }

                diagonal = up;
            }
        }

        return bestSide * bestSide;
    }
}

Burst Balloons

LeetCode 312 · interval DP
1. Goal / Pattern
Maximize reward when removing an item changes its neighbours; choose the last removed item in each interval.
2. Best Approach
O(n³) time, O(n²) space.
3. DP State
dp[left][right] = maximum coins from bursting all balloons strictly inside open interval (left,right).
4. Transition + Base
Choose k as last burst: a[left]·a[k]·a[right] + dp[left][k] + dp[k][right]. Add sentinel 1 at both ends.
5. Iteration Order
Increase interval width so all smaller open intervals are ready.
7. Catch / Memory Hook
Choose last, not first: last has stable neighbours. Memory hook: “last operation fixes the boundary.”
8. Similar / Difference
Rectangle Cutting chooses a first cut; Burst Balloons chooses a last operation to make its boundary deterministic.
9. Interview One-Liner
“I choose the final balloon in an interval because its surviving neighbours are then known.”
6. Full Java 17 Code — LeetCode-ready: class Solution
class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] a = new int[n + 2];
        a[0] = 1;
        a[n + 1] = 1;
        System.arraycopy(nums, 0, a, 1, n);

        int[][] dp = new int[n + 2][n + 2];

        for (int width = 2; width < n + 2; width++) {
            for (int left = 0; left + width < n + 2; left++) {
                int right = left + width;

                for (int last = left + 1; last < right; last++) {
                    dp[left][right] = Math.max(
                        dp[left][right],
                        a[left] * a[last] * a[right] + dp[left][last] + dp[last][right]
                    );
                }
            }
        }

        return dp[0][n + 1];
    }
}

Best Time to Buy and Sell Stock with Cooldown

LeetCode 309 · state machine
1. Goal / Pattern
Maximize stock profit with one share at most and one mandatory cooldown day after selling.
2. Best Approach
O(n) time, O(1) space.
3. DP State
hold = best profit while holding; sold = sold today; rest = not holding and eligible to buy.
4. Transition + Base
newHold=max(hold,rest-price); newSold=hold+price; newRest=max(rest,sold).
5. Iteration Order
Process days forward; calculate all new states from the old states before overwriting.
7. Catch / Memory Hook
Do not let sold buy next day. Memory hook: “sold today cannot buy tomorrow.”
8. Similar / Difference
House Robber has positional states; cooldown needs explicit legal-status states because actions alter future permissions.
9. Interview One-Liner
“I model holding, just sold and resting states so illegal cooldown transitions cannot occur.”
6. Full Java 17 Code — LeetCode-ready: class Solution
class Solution {
    public int maxProfit(int[] prices) {
        if (prices.length == 0) return 0;

        int hold = -prices[0];
        int sold = Integer.MIN_VALUE / 4;
        int rest = 0;

        for (int i = 1; i < prices.length; i++) {
            int nextHold = Math.max(hold, rest - prices[i]);
            int nextSold = hold + prices[i];
            int nextRest = Math.max(rest, sold);

            hold = nextHold;
            sold = nextSold;
            rest = nextRest;
        }

        return Math.max(sold, rest);
    }
}

Distinct Subsequences

LeetCode 115 · 1D string count
1. Goal / Pattern
Count ways to form target t as a subsequence of source s.
2. Best Approach
O(|s|·|t|) time, O(|t|) space. Use long internally.
3. DP State
dp[j] = number of ways to form first j characters of t from scanned source prefix.
4. Transition + Base
When source char matches t[j-1], dp[j]+=dp[j-1]. Base dp[0]=1.
5. Iteration Order
Source forward; target backward so one source character cannot be reused in one subsequence.
7. Catch / Memory Hook
Memory hook: “backward target loop = source character used once.”
8. Similar / Difference
LCS maximizes a common subsequence length; this counts all possible source-position matchings for a fixed target.
9. Interview One-Liner
“A matching source character extends every way that already formed the previous target prefix.”
6. Full Java 17 Code — LeetCode-ready: class Solution
class Solution {
    public int numDistinct(String s, String t) {
        long[] dp = new long[t.length() + 1];
        dp[0] = 1;

        for (int i = 0; i < s.length(); i++) {
            for (int j = t.length(); j >= 1; j--) {
                if (s.charAt(i) == t.charAt(j - 1)) {
                    dp[j] += dp[j - 1];
                }
            }
        }

        return (int) dp[t.length()];
    }
}

Most Common DP Bugs

Wrong base case: define empty prefix / sum 0 / one interval before transition.
Wrong loop direction: forward lets current item repeat; backward blocks reuse.
Overwriting old row: use prev/cur when all dependencies must read prior position.
Not resetting arrays: clear next mask, current row and memo between iterations/tests.
int overflow: use long for counts, rewards, sums and pre-mod products.
Permutations vs combinations: sum outer = ordered; item outer = unordered.
Unreachable state: min DP starts INF; max DP can need negative INF; boolean starts false.
Strictness error: LIS uses first ≥, Projects requires end < start, strict Fenwick queries rank−1.
Dropped ties: lexicographic/frontier DP may require every tied best state, not just one.
